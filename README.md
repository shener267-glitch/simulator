# National Strategy（仮）

HOI4のような国家ストラテジーゲームとして最低限成立するプロトタイプ。
「日本政治シミュレーションゲーム」プロジェクトの土台として、まず汎用の
国家ストラテジーの基礎部分だけを作っている——政治・国家方針まで進んだ
現在も、日本政治向けの本格的な改造（国会・選挙・派閥など）はまだ行わない。

公開先: https://shener267-glitch.github.io/simulator/

## 方向転換の経緯

- **v0.1〜v0.3**: 実在の日本と2024年10月1日を舞台にした政治シミュレーション。
- **Phase 1**: 指示書により方向を変え、特定の国・時代に縛られない国家
  ストラテジーの土台（世界地図・国家選択・ゲーム内時間・基本UI）を先に作った。
- **Phase 2（現在）**: 政治システムと国家方針（National Focus）を追加。
  HOI4型のツリー構造を先に成立させ、その後のPhaseで「日本政治にしか
  存在しない仕組み」へ置き換えていく計画（指示書18章）。

## 基本ループ

```
タイトル → 国家選択 → ゲーム開始 → 政治画面を開く → 国家方針を確認
  → 国家方針を選択 → ゲーム時間を進める → 国家方針が進行
  → 政治力・支持率などが変化 → 国家方針完了 → 次の国家方針を選択
```

## 政治システム

🏛政治画面に、国家指導者（石破茂／石破内閣——固定の登場人物ではなく、
政権交代で差し替わる値として持たせてある）、⭐政治力（時間経過で
1日あたり一定量が蓄積し、国家方針の開始に使う）、📊政府支持率、
⚖️安定度、👥政党一覧（自民・立憲・維新・公明・共産・国民・れいわ・
社民の8党、2024年10月時点のおおよその議席・支持率）を表示する。
政治行動（政党調整・支持率確認など）はまだ仮画面——本格的な操作は
指示書17章のとおり後のPhaseで足す。

## 国家方針（National Focus）

🌳国家方針ツリーは、世界地図と同じ`usePanZoom`フック（パン・ズーム・
タップ判定を一本化した自前実装）でパン・ズームできる。日本の方針は
「政権発足」（発足時点で完了済み扱い）を根に、国内政策・外交政策の
二本柱へ分岐し、経済政策の下で財政拡張／財政再建の二方向にさらに
分かれる14件のツリー（指示書8・13章の例をまとめたもの）。

各方針は名前・説明・所要期間・前提条件・必要政治力・完了時の効果を持ち、
選ぶと政治力を消費してその場で進行を始める。ゲーム内時間が進むにつれて
`daysElapsed`が積み上がり、所要日数に達すると自動的に完了して効果が
適用され、ゲームが一時停止して確認画面が出る（指示書15章）。同時に
進められる方針は一つだけ（指示書11章）。

使えるEffectは指示書14章の8種類——`add_political_power` /
`modify_political_power_gain` / `modify_stability` /
`modify_government_support` / `modify_party_popularity` /
`add_national_modifier` / `trigger_event` / `unlock_focus` ——を
すべて実装した。`unlock_focus`は「アジア外交」から「地域安全保障協力」
（`requiresUnlock`付き、前提条件を満たしても解禁されるまで選べない）を
解禁する例として、`trigger_event`は「財政健全化」完了時に簡易イベント
（確認するだけの一枚のお知らせ、指示書16章）を引く例として、それぞれ
ツリーの中に組み込んである。

内容（方針名・数値・効果）はこのゲームのための創作【ゲーム上の設定】。
「経済再生政策」の所要日数と完了効果だけは指示書に明記された数値を
そのまま使っている。

## 国と政治データの扱い

`GameState.countries`が、その時点の国家データの唯一の情報源。国家選択・
地図・国家情報パネルは、静的なカタログ（`data/countries.ts`）を直接見ず、
必ず`state.countries`から検索する——後のPhaseで人口や経済が変化する
ようになったとき、静的カタログのままだと変化が反映されない、という
落とし穴を避けるための決め方。政治データ（`GameState.politics`）は
プレイヤーの国のみを持ち、日本以外はまだ政党データも国家方針も
用意していない。

## 世界地図・国家方針ツリーの操作

パン・ズームは`src/hooks/usePanZoom.ts`に一本化してあり、世界地図と
国家方針ツリーの両方が同じ操作感になる。タップの成立判定はネイティブの
`click`イベントに頼っていない——`setPointerCapture`をかけた要素の内側
では、環境によってはSVGの子要素へclickが届かないことがあるため、
ドラッグでない一本指操作の終わりに`elementFromPoint`で実際に何の上に
指があるかを調べて選択を確定させている（Playwrightでの検証中に実際に
踏んだ不具合で、既存のゲームエンジンの模倣ではなく実地で見つけて直した）。

## 開発

```
npm install
npm run dev      # http://localhost:5173/
npm test
npm run build
```

`main` への push で GitHub Actions がテスト・ビルドを実行し、GitHub Pages へ
公開する（`.github/workflows/deploy-pages.yml`）。本番ビルドのみ `base` に
`/simulator/` が付く。

## 次の段階で作るもの

指示書23章の方針どおり、国会・選挙・法案・与党内派閥・連立・内閣改造・
不信任・政権交代、経済・外交・研究・軍事の各画面の実データ化は、
このPhaseでは行わない。国家方針そのものの「日本化」（政策決定→党内調整
→政府内調整→国会審議→成立、という手続きへの置き換え）もPhase 3以降。
