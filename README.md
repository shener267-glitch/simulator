# 総理大臣人生シミュレーター

総理大臣という職業に就いた一人の人間の人生をシミュレーションするゲーム。
政策だけでなく、家族・睡眠・疲労・食事・人間関係を含めて、その人生を体験する。

公開先: https://shener267-glitch.github.io/simulator/

## v0.3 の範囲

2026年6月6日（土）**06:00 から就寝まで、一日を最後まで通せる**。

前日6月5日に首班指名・親任式・内閣発足・記者会見・初閣議を終えた翌朝から始まる。
公邸にはまだ入居しておらず、舞台は議員宿舎。引っ越しは後日の出来事として残してある。

v0.1 は「行動一覧から選ぶ → 文章を読む → 一覧に戻る」の繰り返しだった。
v0.2 で操作体系を入れ替え、v0.3 でそれを一日ぶんに伸ばした。プレイヤーが毎回

> 今どこにいて、次の予定まで何分あって、その時間を何に使うか

を決めるゲームになっている。「次へ」を押して出来事を眺める形には戻さない。

```
06:00  起床（議員宿舎・寝室から開始）
       自由行動  115分
07:55  議員宿舎を出発（5分・官邸へ）
08:00  ぶら下がり（10分）

       自由行動

       → どれを選んでも、党幹部との会談は10:45に繰り上がる

10:45  党幹部との会談（40分）  ← 朝に資料を読んだかどうかが、ここで形になる
```

### 中核システム

画面の下に四つの入口が常にある。

```
💪 行動    💬 話す
🚪 移動    🎒 アイテム
```

**場所**が何をできるかを決める。議員宿舎は廊下をハブにした五部屋（寝室・風呂・
リビング・書斎・廊下）、官邸はエントランス・総理執務室・秘書官室で、移動は一分。
風呂で資料は読めないが、スマートフォンは使える。リビングでしか朝食はとれず、
妻もそこにしかいない。**建物をまたぐ移動はプレイヤーには開かれていない** —
07:55の出発と20:00の官邸発だけが運ぶ。総理が自分の行き先を決められないことの、
いちばん素朴な形にしてある。

**時間帯**も場所と同じ扱いにしてある。朝刊は朝にしかなく、夕食は夜にしかない。
外れているものは灰色にせず、そもそも一覧に出さない。

**行動**は複数のセグメントに分かれている。一覧には必ず「15〜40分」のように
**幅**で出し、選んだあとに具体的な長さを選ぶ。始めたあとも一区切りごとに続けるか
やめるかを選べる。選んだ長さは目安であって縛りではない。途中でやめれば、消化した
分の時間だけを消費する。次の予定に入らない長さも**警告つきで選べる** — 押せなく
はしない。跨いだぶんは中断され、残っていた分だけが課金される。

**予定**は跨げない。予定を跨ぐセグメントは中断され、途中まで読んだところは
保存されて、あとで続きから再開できる。予定の枠は開始時刻に固定してあるので、
着席が一分遅れても終わりは動かない。八件並んだ一日で遅れが積み上がらない。

**会議**は文章を読むだけの場面ではない。八件すべてに選択肢があり、枠の中で分を
使う。40分の枠に10分の話題は四つしか入らないので、**何を聞かずに終えるか**が
その会議の中身になる。会議が次の予定を押し出すことはない。

**割り込み**は予定とは別の扱いになる。着信はセグメントを途中で切らず、切れ目で
鳴って三択を出す。後回しにすればスマートフォンに残るが、読むにも時間はかかる。

**話す**は入れ子のメニューになっている。相手を選び、指示を出すか相談するかを
選び、話題を選ぶ。沢渡（政務担当）と篠塚（事務担当）は、同じ話題に別のことを
返してくる。電話アプリからも同じ会話に入れる。

### 🧠 内心

ToDoリストではない。チェックボックスも、件数も、達成率もない。気になっている
ことが最大二行、現在地の画面に出るだけで、**無視して一日を終えることもできる**。
間に合わなくなった内心は急かさず、黙って消える。

無視した結果は、あとで形になって返ってくる。この日の軸は経済対策で、

```
06:00〜  内心「昨夜届いた経済対策の資料に、まだ目を通していない」
   ↓
資料を読む   最後まで → 四ページ目の試算まで頭に入る
             途中まで → 大筋は分かる
   ↓
10:45 党幹部との会談
   読んだ    → 「四ページ目の試算について確認したい」と切り出せる
   流し読み  → 一般論までは言えるが、聞き返されると詰まる
   読まず    → 「秘書官に説明させる」「後で確認する」しか出ない
```

点数はつかない。ただ、そのときに手がないだけになる。

### 体調と就寝

体調（疲労・空腹）は内部的に数値で持つが、画面には五マスの目盛りと「低/中/高」、
それに文章でしか出さない。数字はどこにも出ない。時間が経つだけで消耗するので、
仮眠や食事を削れば今の時間は増え、あとで返すことになる。

疲労には**時刻とともに上がる床**がある。仮眠も入浴も何度でもできるが、起きて
いた時間そのものは休んでも消えない。抜けるのは寝てからで、それは翌朝の話になる。

就寝は自分で決める。夜、宿舎の寝室で、予定が全部済んでいるときだけ選べる。
早く寝れば翌朝に持ち越す疲労が減り、遅いほど残る。決めなければ24:00で一日が
閉じる。咎める文章は出ない。

### 起床シーン

06:00の起床だけは、短いカットを一画面ずつ送る導入にしてある。文字送りの途中で
タップすると全文が出て、もう一度タップで次へ進む。この一文字ずつの表示は起床
シーンに限り、ニュース・会話・メニューでは使わない。時間は消費しない。

### 一日の記録

朝／午前／午後／夕方／夜で区切り、時間帯ごとの内訳を出す。「合計」はどう遊んでも
一日ぶんになって意味を失うので、置いていない。

### 見た目

黒（#0B0D12）を地に、金（#C8A96B）を時刻・選択・見出しのアクセントとして使う。
赤（#C94B4B）は突発の連絡と中断だけに限る。書体は Noto Sans JP に統一し、階層は
太さと大きさで作る。時刻と英字ラベルにのみ Inter を使う。フォントの読み込みに
失敗しても端末標準の書体で成立するようにしてある。iPhone の縦画面を最優先で
組んでいる。

### 危機イベントの土台

`src/types/crisis.ts` と `src/data/crises/catalogue.ts` に、災害・安全保障・
外交・経済・保健・政局・個人にわたる46件を、主管省庁・親子関係・予兆・確率・
季節・所要時間・日程への影響つきで置いてある。

**このバージョンでは一件も発火しない。** 発火の仕組みより先に繋がりを決めて
おきたかったのと、**予兆は起きる予告ではない**という形を先に固定しておきたかった
ため。予兆が出て何も起きないまま終わることの方が多い、という構造にしてある。

### v0.3 で作っていないもの

本格的な外交・国会・選挙・支持率計算・派閥・戦争・災害シミュレーション、AI API、
オンラインDB、複雑な経済シミュレーション、複数日のシナリオ。危機イベントは型と
カタログのみ。人格フラグは行動から積み上がるが、いまは振り返りに一行出すだけで、
NPCの反応には反映しない。

## 開発

```
npm install
npm run dev      # http://localhost:5173/
npm test
npm run build
```

`main` への push で GitHub Actions がテスト・ビルドを実行し、GitHub Pages へ
公開する（`.github/workflows/deploy-pages.yml`）。本番ビルドのみ `base` に
`/simulator/` が付く。
