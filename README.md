# National Strategy（仮）

HOI4のような国家ストラテジーゲームとして最低限成立するプロトタイプ。
「日本政治シミュレーションゲーム」プロジェクトの土台として、まず汎用の
国家ストラテジーの基礎部分だけを作っている——今回はまだ日本政治向けの
改造は行わない。

公開先: https://shener267-glitch.github.io/simulator/

## 方向転換（v0.3 → Phase 1）

これまで（v0.1〜v0.3）は、実在の日本と2024年10月1日を舞台にした政治
シミュレーションを作っていた。今回、指示書により方向を変え、**特定の国・
時代に縛られない、拡張可能な国家ストラテジーの土台**を先に作ることになった。
日本の政治要素（内閣・国会・危機イベントのカタログなど）はいったんすべて
外し、後のPhaseで「HOI4型の政治・国家方針・経済・研究」を足し、そこから
必要な日本独自システムへ置き換えていく計画。

## 基本ループ

```
タイトル → 国家選択 → ゲーム開始 → 時間が進む → 一時停止 → 国家情報を見る
```

タイトルで「開始」→ 国家選択画面で国を選ぶ（デフォルトは日本）→
「この国で開始」→ メイン画面で時間が自動的に進み、一時停止・速度変更・
地図の閲覧・国家情報の確認ができる。

## 世界地図

`world-atlas`（Natural Earthベースの公開地理データ、パブリックドメイン
相当）の110m解像度データを`topojson-client`でGeoJSONに変換し、`d3-geo`の
Natural Earth図法でSVGパスとして描画している。既存ゲームの画像・アイコンは
使っていない——実在の国境線データを、ここで独自に組んだ見た目で描いている。

ズーム・パンはPointer Events APIで自前実装した（マウスのドラッグ・
ホイールと、タッチのドラッグ・ピンチを同じ「アンカー点を指の下に保つ」
計算で扱う）。国名は`i18n-iso-countries`のISO 3166-1数字コード→日本語名
辞書を使うので、プレイ可能な7か国以外をクリックしても名前だけは出せる。

## 国家データ

```
country
├─ id / isoNumeric（地図の境界データと対応するコード）
├─ name / flag / capital / population
├─ government / politicalSystem
├─ economy / military / diplomacy / provinces（Phase 1では空。後で拡張）
└─ playable
```

`src/data/countries.ts`にプレイ可能な7か国（日本・アメリカ・中国・
ロシア・イギリス・フランス・ドイツ）を実データで用意した。首都・政治
体制は広く確認された事実、人口は2024年前後の概算（日本のみ指示書に
書かれていた数値をそのまま使用）——このPhaseでは表示用の値でしかなく、
国家運営の計算にはまだ使わない。国を増やすときはここに一件足すだけでよい。

## ゲーム内時間

```
gameTime
├─ year / month / day / hour / minute
└─ speed（0=一時停止, 1/2/4/8倍）
```

年・月・日・時・分・速度を持つ独立した構造体（`src/types/gameTime.ts`）。
繰り上がり（分→時→日→月→年、うるう年判定込み）は`src/engine/gameTime.ts`
がこの構造体だけで完結させている——他の日時表現に依存しない。速度は
1倍で現実の1秒がゲーム内1分に相当する（ブラウザで遊び切れる速さとして
選んだゲーム上の設定）。デフォルトの開始日時は2024年10月1日 08:00だが、
値であって仕様に固定された定数ではない。

## 基本UI

画面下部に8カテゴリ（🏛政治・💰経済・🌍外交・🪖軍事・🔬研究・🏭生産・
🕵情報・📊国家）。「国家」以外はPhase 2で実装予定の仮画面。

見た目はダーク基調・情報量重視のパネル式。フォントはDotGothic16
（ドット字形の和文フォント、SIL OFL）を軸に、Noto Sans JP→システム標準
の順にフォールバックする——特定ゲームの画像素材は使っていない、独自の
組み方。

## Phase 1で作っていないもの（指示書12章）

国家方針、政治力、国会、法律、選挙、詳細な経済、生産ライン、技術研究、
軍隊、戦闘、外交交渉、諜報、イベントシステム、AI国家の高度な意思決定。
コード構造としては後から足しやすい形にしてある（国家データ・地図データ・
時間システムが互いに独立しているため）。

## 開発

```
npm install
npm run dev      # http://localhost:5173/
npm test
npm run build
```

`main` への push で GitHub Actions がテスト・ビルドを実行し、GitHub Pages へ
公開する（`.github/workflows/deploy-pages.yml`）。本番ビルドのみ `base` に
`/simulator/` が付く。
