# National Strategy（仮）

HOI4のような国家ストラテジーゲームとして最低限成立するプロトタイプ。
「日本政治シミュレーションゲーム」プロジェクトの土台として、まず汎用の
国家ストラテジーの基礎部分だけを作っている——経済・研究まで進んだ現在も、
日本政治向けの本格的な改造（国会・選挙・派閥など）はまだ行わない。

公開先: https://shener267-glitch.github.io/simulator/

## 方向転換の経緯

- **v0.1〜v0.3**: 実在の日本と2024年10月1日を舞台にした政治シミュレーション。
- **Phase 1**: 特定の国・時代に縛られない国家ストラテジーの土台（世界地図・
  国家選択・ゲーム内時間・基本UI）。
- **Phase 2**: 政治システムと国家方針（National Focus）。
- **Phase 3**: 経済（GDP・財政・予算配分・経済政策）と研究
  （技術ツリー・研究枠）を追加し、「国家には無限の金・人・時間があるわけ
  ではない」というトレードオフを持ち込んだ。
- **Phase 4**: 外交（関係値・条約・貿易・スタンス・世界情勢）を追加した。
- **Phase 5（現在）**: 軍事・安全保障（人員・陸海空/ミサイル/その他戦力・
  基地・部隊・作戦・生産・軍事研究・情報・戦争）を追加した。指示書のとおり、
  HOI4型のシステムをまず成立させる段階——日本政治にしか無い仕組みへの
  置き換えは今後のPhase。

## 経済システム

GDP・成長率・税収・政府支出・財政収支・政府債務・インフレ率・失業率を、
それぞれ独立したデータとして持つ（指示書2章、経済を一つの数字にしない）。
政府支出は7分野（社会保障・防衛・公共事業・教育研究・外交・産業政策・
その他）の予算配分の合計として導く——別に持たない。防衛費の初期値
¥7.9兆は指示書4章の例をそのまま使った。

経済政策（減税・増税・公共投資・社会保障拡充・歳出削減・補助金・産業支援・
規制緩和の8種）は、決定した瞬間に全部が変わるのではなく、即時・中期・
長期の段階に分けて時間差で効いてくる（指示書8章）。予算に触れる政策は、
その分野の年間予算そのものを恒久的に動かす。

経済状況は政治へゆるやかに影響する（指示書9章）——成長率・失業率・
インフレ率のしきい値から、1日あたりごく小さな支持率・安定度の変化を
積み上げる。「単純な数式だけで政治の結果を決めない」という指示のとおり、
大きく動かしたいときは政策やイベントの役割にしてある。

## 研究システム

「基礎科学」を根に、情報・AI／エネルギー／産業技術／航空宇宙の5カテゴリー・
23技術のツリー（指示書14章が名指しした項目が中心）。指示書15章が所要日数を
明記した3件（コンピューター基礎180日・AI基礎240日・次世代半導体300日）は
その数値をそのまま使った。研究枠は基本2——同時に2つの技術を進められる。

「AI応用」の完了で`unlock_tech`効果により「量子コンピューティング」が
解禁される——前提条件を満たしても、解禁されるまでは選べない、という
国家方針と共通の仕組みを研究側でも実装した。

## 国家方針↔研究の接続（指示書19章）

政治の国家方針ツリーに「科学技術立国」を追加（研究速度+10%）。既存の
「財政再建」には研究速度-3%を追加した——どちらも指示書19章が挙げた
例そのもの。`FocusEffect`に`modify_research_speed`を足しただけで、
既存の国家方針システムを壊さずに実現できた。

## 国家概要への表示（指示書20章）

📊国家タブは、プレイヤー自身の国だけが持つ`NationalOverviewPanel`に
差し替えた（地図で他国を覗いたときの簡易表示とは別）。基本情報に加えて
🏛政治（支持率・安定度）💰経済（GDP・成長率・インフレ・失業率・政府支出）
🔬研究（研究枠・研究中の件数）を一画面にまとめて表示する。

## 直した不具合

地図・国家方針ツリー・研究ツリーで共有している`usePanZoom`のクランプ
計算に、ズームするほど地図の端に届かなくなる不具合があった——「見える
範囲の余裕」をscaleに比例させていたのが原因。画面幅に対する固定の
余裕に直し、回帰テストを足した（`tests/hooks/usePanZoom.test.ts`）。

また、Phase 1から`GameState.countries`が誰にも読まれず、研究の
「基礎科学」が最初から完了扱いになっていない、という2件の見落としを
Phase 3の実装中に見つけて直している（詳しくはコミット履歴を参照）。

## 外交システム

関係値を一つの数字にせず、基礎値＋内訳（`RelationModifier[]`）として持ち、
政府間・経済・軍事の三本のメーター（0〜100）を別に持つ——政治・経済・
研究で使ってきた「閉じた語彙のEffectシステム」（`DiplomacyEffect`）を
そのまま外交にも適用した。外交行動・条約はどちらも、経済政策と同じ
「決定した瞬間に段階を絶対時刻へ落とし込み、`TICK`で順に適用する」形。

条約は関係値のしきい値を満たさないと提案できず、種類ごとの破棄しきい値
（例: 友好条約は関係値-30未満で自動破棄）を`TICK`のたびにスイープする。
簡易チェックボックス交渉画面では、条約の種類を選んだあと任意の追加条項
（例: 通商協定の「関税優遇条項」）をチェックで足せる——本格的な交渉AIは
作っていない。

貿易は原油・鉄鉱石の輸入充足率が相手国との関係値にゆるやかに連動し
（原油はロシア、鉄鉱石は全体平均を代理指標にする簡略化）、不足分が
economy側のインフレ率・GDP成長率へじわりと効く——指示書が要求した
「石油価格→外交→政治→国家方針→関係」という一連の流れの、貿易↔経済の
部分を実装した形。

他国AIは`personality`（協調的・強硬・孤立主義・実務的）ごとの確率で、
外交行動だけを起こす簡易なもの——経済・政治・軍事まで含む本格AIは
今回作っていない。将来ここを差し替えれば行動の中身だけ変えられる、
という指示書の要求どおりの構造にしてある。

## 国家方針↔外交の接続

`FocusEffect`に`modify_relation`を追加し、既存の「日米関係強化」に
アメリカとの関係値+8、「アジア外交」に中国との関係値+8を足した——
指示書が例に挙げた二つの方針をそのまま使い、新しいツリーは作っていない。
指示書のモックアップにある韓国は、プレイ可能な7か国のカタログに含まれて
いないため、Phase 4では対象から外した（カタログを増やす話は別途）。

## スコープの簡略化（指示書の「作り込みすぎない」方針に沿って）

- 首脳会談は、プレイヤーが提案してから準備が整うまでの一本の流れに
  まとめた——他国側から突発的に招請が来る経路は今回作っていない
  （通知そのものは承諾／延期／辞退の3択で、双方向に拡張できる形）。

## 軍事システム

軍事力を「総兵力」の一つの数字にせず、人員・陸上・海上・航空・ミサイル・
その他（衛星・サイバー・電子戦・情報）を、それぞれ独立した能力指数
（0〜100）として持つ（指示書2章）。政治・経済・研究・外交で使ってきた
「閉じた語彙のEffectシステム」（`MilitaryEffect`）をそのまま軍事にも
適用し、防衛予算はPhase 3の`economy.budget.defense`をそのまま使う
（新しい予算フィールドを増やしていない）。

作戦地図は、世界地図が使う実在の地理データ（world-atlas）とは別に、
日本周辺12地域を簡略化したschematic図で表現した——指示書自身のモックアップ
がASCIIスケッチであることに合わせた判断で、実在の座標に正確に投影する
本格的な地図描画は今回作っていない。

生産はHOI4型：工場数×生産効率×（防衛予算÷¥7.9兆という指示書の基準額）
で1日あたりの生産量を求め、累積が1単位ぶん貯まるたびに対応する戦力の
能力指数へ少しずつ還元する——「防衛費を増やせば無条件に軍事力が増える
わけではない」という指示書14章の釘刺しどおり、予算を増やしても即座には
戦力が増えない。

各国の軍事情報は、実在国のおおよその規模感を踏まえたゲーム上の近似値
（`FOREIGN_MILITARY_BASELINE`、断定的な軍事評価ではない）を基準に、
確度に応じたノイズを乗せてドリフトさせる——プレイヤーが世界のすべてを
知っている状態にはしない、という指示書20・21章の要求どおり。

武力攻撃は、関係値が-70以下まで悪化した相手にだけ、ごくわずかな確率で
発生する——通知が立った時点で戦争状態が始まり、プレイヤーは
防衛作戦／同盟国へ支援要請／国際社会へ声明／外交交渉の4択で応じる。
戦争画面では、作戦を割り当てた方面が持ちこたえやすくなる、という
国家レベルの意思決定を中心にし、部隊を1マスずつ動かす詳細な戦闘計算は
指示書26章の方針どおり作っていない。

## 研究↔軍事の接続（指示書19・30章）

研究ツリーに「軍事基盤」を根とする軍事カテゴリーを追加し、防勢重視・
機動重視・海洋防衛・航空優勢・統合防衛の5ドクトリンと、防空技術→統合
防空→次世代防空、艦艇技術→次世代護衛艦、新型ミサイルという枝を作った。
既存の「航空技術」（aerospace）から「次世代戦闘機」への接続は、指示書の
ツリー例をそのまま再現している。`TechEffect`に`modify_military_capability`
を足しただけで、既存の研究システムを壊さずに実現できた。

- 部隊は実在の編成に沿った代表5個部隊・艦隊3・航空団3にとどめた——

## 直した不具合（Phase 5）

Modal（ボトムシート）のスライドイン演出`animate-sheet-up`が
`fill-mode: both`だったため、演出が終わったあとも`transform: translateY(0)`
が要素に残り続けていた。CSSの仕様上、`transform`が`none`でない要素は
子孫の`position: fixed`の基準（containing block）になる——このため、
Modalの中にさらにModalをネストする画面（例: 部隊詳細から開く移動先
選択）で、内側のModalの`fixed inset-0`がビューポートではなく外側の
カードを基準に配置され、実際に描画される位置と実際にクリックが当たる
判定がずれる不具合があった。Panelの中にModalをネストする（既存のほぼ
全画面）場合はPanel自体がビューポート大なので偶然問題が起きていなかった
——Phase 5で初めてModalの中にModalをネストする画面（部隊の移動先選択）
を作ったことで表面化した。Playwrightの実クリックで発見し、
`tailwind.config.ts`のアニメーションを`both`から`backwards`に直して
解消した（見た目の演出自体は変わらない）。

そのまま維持している。

- [x] プロヴィンス制（地域12個の内側を21プロヴィンスに細分化。所有国・
      地形・インフラ・補給・都市・港・基地・要塞化・係争状況を持つ）
- [x] 師団・艦隊を選択してプロヴィンスをタップ→移動命令（複数選択で
      同時移動も可能）
- [x] 移動所要時間（プロヴィンス間の距離とインフラ水準から算出、地図上
      に「移動中」表示）
- [x] 係争プロヴィンスへの移動＝攻撃。到着時に簡略化した陸上戦闘を解決
      （人員・装備充足・士気・地形・要塞化・敵戦力推定から勝敗判定）
- [x] 前線の二重管理：既存の「作戦（Operation）」による方面単位のAI運用と、
      師団単位の手動移動・攻撃命令を、互いを妨げずに併存させた
- [x] 艦隊の直接移動（プロヴィンス単位、海のプロヴィンスへのみ）
- [x] 航空団の作戦地域指定（航続圏内のいずれかの地域を選んで設定）

### プロヴィンス制の設計

`Province`は地域（既存の12`MilitaryRegionId`）の内側にある細かい単位
（陸21・海3の計24。実際には陸18・海3の21件、9つの陸上地域に2つずつ）。
部隊・艦隊・基地は、集計・前線表示に使う既存の`regionId`（地域）と、
移動・戦闘に使う新しい`provinceId`（プロヴィンス）の両方を持つ——
既存の方面別状況表示や戦争システムを壊さずにプロヴィンス粒度を足すための
二重管理。

**`Province.contested`（係争中）は純粋にゲーム上の戦時フラグであり、
現実の領有権主張ではない。** 戦争開始時に前線の地域に属するプロヴィンス
へ機械的に立て、プレイヤーが勝利すると消える。`ownerCountryId`自体は
常に`"JPN"`のままで変化しない——他国への領有権の割り当ては一切行って
いない。

移動所要時間は「距離（プロヴィンス間のホップ数）×1.2×
1/(1+平均インフラ÷10)」で概算し、最短0.25日とした——道路・鉄道を
個別にモデル化しない、指示書の「作り込みすぎない」方針どおりの簡略化。

陸上戦闘は「攻撃側戦力＝人員充足率×装備充足率×士気」対「防御側戦力＝
敵戦力推定値×(1+要塞化補正+地形補正)」の差で勝敗を決める簡略化——
detailed combatは指示書が明示的に後回しにした項目のままで、今回も
本格的な戦闘計算は作っていない。

### スコープの簡略化（今回も維持）

- 前線のAI運用（既存の作戦システム）と手動の師団移動は、互いを排他的に
  していない——師団を作戦に割り当てたまま手動移動もできる。本格的な
  前線ライン描画UIは作っていない（指示書§9が構造のみの先送りを許容）。
- 師団の内部編成（歩兵大隊・戦車大隊・砲兵など）や、師団→旅団／連隊→
  師団→軍→軍集団という指揮階層は、型レベルの拡張余地を残すのみで
  今回は実装していない（指示書§8・§9の明示的な許容範囲）。
- 海戦・空戦そのものの戦闘計算は行わない——艦隊移動・航空団の作戦地域
  指定という「命令を出す」操作までを実装した。

## 次の段階で作るもの

指示書の方針どおり、詳細な戦闘・詳細な兵站・電子戦・サイバー戦・宇宙戦・
核戦略は、このPhaseでは本格実装しない。Phase 6以降で、諜報・情報戦→
戦争・戦闘の高度化→国会・選挙・政党→国際機関・世界システムを順番に
追加していく計画。
