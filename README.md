# 総理大臣人生シミュレーター

総理大臣という職業に就いた一人の人間の人生をシミュレーションするゲーム。
政策だけでなく、家族・睡眠・疲労・食事・人間関係を含めて、その人生を体験する。

公開先: https://shener267-glitch.github.io/simulator/

## v0.2 の範囲

2026年6月6日（土）05:00〜08:00 の朝フェーズのみ。

前日6月5日に首班指名・親任式・内閣発足・記者会見・初閣議を終えた翌朝から始まる。

v0.1 は「行動一覧から選ぶ → 文章を読む → 一覧に戻る」の繰り返しだった。
v0.2 で操作体系を入れ替え、プレイヤーが毎回

> 今どこにいて、次の予定まで何分あって、その時間を何に使うか

を決めるゲームにしてある。

```
05:00  起床（公邸・寝室から開始）
       自由行動
06:10  官房長官から着信
       → 中断して確認する / 後回しにする / 無視する
       → どれを選んでも、ブリーフィングは06:30に繰り上がる
       自由行動
06:30  秘書官による朝のブリーフィング（30分）
       自由行動
07:30  官邸入り（5分・現在地が官邸に変わる）
       自由行動
07:45  官房長官との打ち合わせ（15分）
08:00  朝フェーズ終了 → 朝の記録
```

### 中核システム

画面の下に四つの入口が常にある。

```
💪 行動    💬 話す
🚪 移動    🎒 アイテム
```

**場所**が何をできるかを決める。公邸は廊下をハブにした五部屋（寝室・風呂・
リビング・書斎・廊下）で、移動は一分。風呂で資料は読めないが、スマートフォンは
使える。リビングでしか朝食はとれず、妻もそこにしかいない。官邸へは07:30の予定が
連れていく。

**行動**は複数のセグメントに分かれている。始める前に長さを選び（10分/20分/30分）、
始めたあとも一区切りごとに続けるかやめるかを選べる。選んだ長さは目安であって
縛りではない。途中でやめれば、消化した分の時間だけを消費する。

**予定**は跨げない。予定を跨ぐセグメントは中断され、実際に残っていた分だけが
消費される。次の予定に入らない長さは、選択肢に出るが選べない。

**割り込み**は予定とは別の扱いになる。着信はセグメントを途中で切らず、切れ目で
鳴って三択を出す。後回しにすればスマートフォンに残るが、読むにも時間はかかる。

**話す**は入れ子のメニューになっている。相手を選び、指示を出すか相談するかを
選び、話題を選ぶ。沢渡（政務担当）と篠塚（事務担当）は、同じ話題に別のことを
返してくる。

行動どうしは繋がっている。朝刊を最後まで読むと隅の小さな記事に気づき、それに
気づいて初めて秘書官に振れる話題が増える。

体調（疲労・空腹）は内部的に数値で持つが、画面には五マスの目盛りと「低/中/高」、
それに文章でしか出さない。数字はどこにも出ない。時間が経つだけで消耗するので、
仮眠や朝食を削れば今の時間は増え、あとで返すことになる。

### 起床シーン

05:00の起床だけは、短いカットを一画面ずつ送る導入にしてある。文字送りの途中で
タップすると全文が出て、もう一度タップで次へ進む。この一文字ずつの表示は起床
シーンに限り、ニュース・会話・メニューでは使わない。時間は消費しない。

### 見た目

黒（#0B0D12）を地に、金（#C8A96B）を時刻・選択・見出しのアクセントとして使う。
赤（#C94B4B）は突発の連絡と中断だけに限る。書体は Noto Sans JP に統一し、階層は
太さと大きさで作る。時刻と英字ラベルにのみ Inter を使う。フォントの読み込みに
失敗しても端末標準の書体で成立するようにしてある。iPhone の縦画面を最優先で
組んでいる。

### v0.2 で作っていないもの

外交・国会・選挙・内閣不信任・政策システム・派閥システム・午前以降のフェーズ、
突発イベントのランダム発生、予定変更の交渉。人格フラグは行動から積み上がるが、
v0.2 では振り返りに一行出すだけで、NPCの反応には反映しない。

## 開発

```
npm install
npm run dev      # http://localhost:5173/
npm test
npm run build
```

`main` への push で GitHub Actions がテスト・ビルドを実行し、GitHub Pages へ
公開する（`.github/workflows/deploy-pages.yml`）。本番ビルドのみ `base` に
`/simulator/` が付く。
