# 日本政治シミュレーションゲーム

「総理大臣」という役職と、日本という国の意思決定システムをシミュレーションする
ゲーム。プレイヤーは特定の一人物ではなく、**総理大臣という役割そのもの**を担う
——在任者が交代しても、ゲームは新しい総理として続く。

公開先: https://shener267-glitch.github.io/simulator/

## v0.3 で作り直したこと

v0.1〜v0.4は、総理大臣という職に就いた一人の人間の私生活（家族・睡眠・食事・
人間関係）を含めて体験するゲームだった。v0.3で軸を大きく変え、**国家運営の
意思決定**そのものを中心に置き直した。私生活の描写はやめ、政治日程・報告・
政策決定・危機対応を中心に据えている。

古い一日完結型（06:00起床〜24:00就寝、分オフセットの時計）もやめ、**実際の
カレンダー日付を起点にした時計**に置き換えた。ゲームは2024年10月1日（火）
朝07:00から始まる——石破内閣が実際に発足した日である【事実】。

## 現在のバージョン（Phase 1 プロトタイプ）

2024年10月1日を、最後まで通しで遊べる最小構成。指示書が求めた10点に対応する。

| # | 要件 | このバージョンでの実装 |
|---|---|---|
| 1 | 時間が自動で進む | `TICK`アクションが1秒(現実)ごとに最大speed分だけ、1分刻みで進める |
| 2 | 一時停止できる | ▶/Ⅱボタン。初期状態は一時停止 |
| 3 | 予定表がある | 🗓️予定シート。`state.appointments`から都度導く |
| 4 | 予定外の情報・出来事が起こる | 報告書がその場で届く。危機イベントは毎分の確率判定で発火しうる |
| 5 | 報告書が読める | 📄報告書シート。読むこと自体は時間を消費しない |
| 6 | 政策を決められる | 📜政策シート。**正解を用意しない**——長所と短所の文章のみ |
| 7 | 国家ステータスが変化する | 政策・会議の判断が、しばらく経ってから遅延反映される |
| 8 | 外交・国会・省庁に触れられる | 🏛️国家の窓（今は静的な参照情報。本格的なやり取りは次段階） |

### 時計

`GAME_START = 2024-10-01`からの絶対分（`totalMinutes`）ですべての時刻を表す。
複数日にまたがっても壊れない。速度は1×〜10×まで。1×は現実の1秒がゲーム内
1分に相当する——ブラウザで実際に遊び切れる速さとして選んだゲーム上の設定で、
現実の時間の流れ方を主張するものではない。

### この日の政治日程

2024年10月1日は、実際に石破内閣が発足した日【事実】。首班指名選挙・親任式・
組閣・認証式・第一回閣議・就任記者会見が、その日のうちに行われた。分刻みの
開始時刻そのものは公表されたタイムテーブルではなく、実際の順序に沿わせた
ゲーム上の割り付け【推測】。

```
10:00  国会本会議 — 首班指名選挙
11:30  皇居 — 総理親任式
13:00  官邸 — 組閣人事の最終調整
19:00  皇居 — 閣僚認証式
20:00  官邸 — 第一回閣議
21:00  官邸 — 就任記者会見
```

各予定は「会議」として開く。文章を読むだけでは終わらせず、枠の中で小さな
判断をさせる——枠を使い切るか、席を立つと決めるまで終わらない。次の予定が
あるときは、必ずその十分前で終わる（`MEETING_GAP`）。会議の仕組みそのものは、
旧バージョンで作った会議エンジン（`engine/meeting.ts`）をほぼそのまま流用した
——設計書28章が独立に、ほぼ同じ仕組みを求めていたため。

### 報告書と政策

報告書は`at`（到着時刻）が来た瞬間に届く。確度は「高・中・低」の三段階までで、
内部の点数は持たない。うち二本は危機カタログと同じ調子の定点観測レポート
（地震活動・サイバー攻撃の監視）で、**乱数とは一切連動していない**——実際に
その危機が起きるかどうかとは無関係に、この日は必ずこの二本が届く。「予兆は
予告ではない」を、統計的な相関を作らずに実現するための書き方。

政策決定に正解は無い。選択肢はどれも長所と短所を文章で書くだけで、選んだ
結果は数日後に国家ステータスへ小さく遅延反映される。

### 危機イベント

`data/crises/catalogue.ts`の46件のカタログ（旧バージョンから、発火の仕組みを
持たないまま作ってあったもの）に、今回はじめて発火の仕組み（`engine/crisis.ts`）
をつないだ。親を持たない危機は毎分ごとに小さい確率で判定し、実際に起きた
ものだけ、その場で子・関連イベントを一回だけ判定する（カタログの `probability`
は、子については「親が起きたときの条件付き確率」として書かれている）。発火すると
その場でゲームが自動停止し、通知を読むまで再開しない。

### 国家ステータス

支持率・GDP成長率・物価上昇率・完全失業率・政府債務・周辺情勢を背景の指標として
表示する。数字そのものでは結果を語らない——最新情報欄のニュース文が主で、
ここはあくまで背景。開始値は2024年10月時点の概算【参考】と、内閣支持率など
ゲーム固有の指標【ゲーム上の設定】を区別して置いてある（`state/initialState.ts`
のコメント参照）。

### 見た目

DotGothic16（ドット字形の和文フォント、SIL OFLライセンスの無料フォント）を
本文に採用し、Noto Sans JP → システム標準の順にフォールバックする。Google
Fontsを読み込めない環境でもフォールバック連鎖でそのまま表示できる。角の丸みは
ほぼ落として、ブロックを積み重ねたような見た目にしてある。配色は黒地に金の
アクセント、赤は緊急のものだけに限る、という旧バージョンからの原則を維持した。

## 次の段階で作るもの

- 会議・報告・政策の中身をこの一日の先まで拡張する（複数日をまたぐ運営）。
- 省庁・国会・外交を、静的な参照情報から実際にやり取りできる窓口にする。
- 危機イベントの対応フロー（対策本部の設置、担当省庁とのやり取り）。
- 本格的な支持率計算・選挙・派閥力学は、指示書23章の方針どおり、当面作らない。

## 開発

```
npm install
npm run dev      # http://localhost:5173/
npm test
npm run build
```

`main` への push で GitHub Actions がテスト・ビルドを実行し、GitHub Pages へ
公開する（`.github/workflows/deploy-pages.yml`）。本番ビルドのみ `base` に
`/simulator/` が付く。
