# National Strategy（仮）

HOI4のような国家ストラテジーゲームとして最低限成立するプロトタイプ。
「日本政治シミュレーションゲーム」プロジェクトの土台として、まず汎用の
国家ストラテジーの基礎部分だけを作っている——経済・研究まで進んだ現在も、
日本政治向けの本格的な改造（国会・選挙・派閥など）はまだ行わない。

公開先: https://shener267-glitch.github.io/simulator/

## 方向転換の経緯

- **v0.1〜v0.3**: 実在の日本と2024年10月1日を舞台にした政治シミュレーション。
- **Phase 1**: 特定の国・時代に縛られない国家ストラテジーの土台（世界地図・
  国家選択・ゲーム内時間・基本UI）。
- **Phase 2**: 政治システムと国家方針（National Focus）。
- **Phase 3**: 経済（GDP・財政・予算配分・経済政策）と研究
  （技術ツリー・研究枠）を追加し、「国家には無限の金・人・時間があるわけ
  ではない」というトレードオフを持ち込んだ。
- **Phase 4（現在）**: 外交（関係値・条約・貿易・スタンス・世界情勢）を
  追加した。指示書のとおり、HOI4型のシステムをまず成立させる段階——
  日本政治にしか無い仕組みへの置き換えは今後のPhase。

## 経済システム

GDP・成長率・税収・政府支出・財政収支・政府債務・インフレ率・失業率を、
それぞれ独立したデータとして持つ（指示書2章、経済を一つの数字にしない）。
政府支出は7分野（社会保障・防衛・公共事業・教育研究・外交・産業政策・
その他）の予算配分の合計として導く——別に持たない。防衛費の初期値
¥7.9兆は指示書4章の例をそのまま使った。

経済政策（減税・増税・公共投資・社会保障拡充・歳出削減・補助金・産業支援・
規制緩和の8種）は、決定した瞬間に全部が変わるのではなく、即時・中期・
長期の段階に分けて時間差で効いてくる（指示書8章）。予算に触れる政策は、
その分野の年間予算そのものを恒久的に動かす。

経済状況は政治へゆるやかに影響する（指示書9章）——成長率・失業率・
インフレ率のしきい値から、1日あたりごく小さな支持率・安定度の変化を
積み上げる。「単純な数式だけで政治の結果を決めない」という指示のとおり、
大きく動かしたいときは政策やイベントの役割にしてある。

## 研究システム

「基礎科学」を根に、情報・AI／エネルギー／産業技術／航空宇宙の5カテゴリー・
23技術のツリー（指示書14章が名指しした項目が中心）。指示書15章が所要日数を
明記した3件（コンピューター基礎180日・AI基礎240日・次世代半導体300日）は
その数値をそのまま使った。研究枠は基本2——同時に2つの技術を進められる。

「AI応用」の完了で`unlock_tech`効果により「量子コンピューティング」が
解禁される——前提条件を満たしても、解禁されるまでは選べない、という
国家方針と共通の仕組みを研究側でも実装した。

## 国家方針↔研究の接続（指示書19章）

政治の国家方針ツリーに「科学技術立国」を追加（研究速度+10%）。既存の
「財政再建」には研究速度-3%を追加した——どちらも指示書19章が挙げた
例そのもの。`FocusEffect`に`modify_research_speed`を足しただけで、
既存の国家方針システムを壊さずに実現できた。

## 国家概要への表示（指示書20章）

📊国家タブは、プレイヤー自身の国だけが持つ`NationalOverviewPanel`に
差し替えた（地図で他国を覗いたときの簡易表示とは別）。基本情報に加えて
🏛政治（支持率・安定度）💰経済（GDP・成長率・インフレ・失業率・政府支出）
🔬研究（研究枠・研究中の件数）を一画面にまとめて表示する。

## 直した不具合

地図・国家方針ツリー・研究ツリーで共有している`usePanZoom`のクランプ
計算に、ズームするほど地図の端に届かなくなる不具合があった——「見える
範囲の余裕」をscaleに比例させていたのが原因。画面幅に対する固定の
余裕に直し、回帰テストを足した（`tests/hooks/usePanZoom.test.ts`）。

また、Phase 1から`GameState.countries`が誰にも読まれず、研究の
「基礎科学」が最初から完了扱いになっていない、という2件の見落としを
Phase 3の実装中に見つけて直している（詳しくはコミット履歴を参照）。

## 外交システム

関係値を一つの数字にせず、基礎値＋内訳（`RelationModifier[]`）として持ち、
政府間・経済・軍事の三本のメーター（0〜100）を別に持つ——政治・経済・
研究で使ってきた「閉じた語彙のEffectシステム」（`DiplomacyEffect`）を
そのまま外交にも適用した。外交行動・条約はどちらも、経済政策と同じ
「決定した瞬間に段階を絶対時刻へ落とし込み、`TICK`で順に適用する」形。

条約は関係値のしきい値を満たさないと提案できず、種類ごとの破棄しきい値
（例: 友好条約は関係値-30未満で自動破棄）を`TICK`のたびにスイープする。
簡易チェックボックス交渉画面では、条約の種類を選んだあと任意の追加条項
（例: 通商協定の「関税優遇条項」）をチェックで足せる——本格的な交渉AIは
作っていない。

貿易は原油・鉄鉱石の輸入充足率が相手国との関係値にゆるやかに連動し
（原油はロシア、鉄鉱石は全体平均を代理指標にする簡略化）、不足分が
economy側のインフレ率・GDP成長率へじわりと効く——指示書が要求した
「石油価格→外交→政治→国家方針→関係」という一連の流れの、貿易↔経済の
部分を実装した形。

他国AIは`personality`（協調的・強硬・孤立主義・実務的）ごとの確率で、
外交行動だけを起こす簡易なもの——経済・政治・軍事まで含む本格AIは
今回作っていない。将来ここを差し替えれば行動の中身だけ変えられる、
という指示書の要求どおりの構造にしてある。

## 国家方針↔外交の接続

`FocusEffect`に`modify_relation`を追加し、既存の「日米関係強化」に
アメリカとの関係値+8、「アジア外交」に中国との関係値+8を足した——
指示書が例に挙げた二つの方針をそのまま使い、新しいツリーは作っていない。
指示書のモックアップにある韓国は、プレイ可能な7か国のカタログに含まれて
いないため、Phase 4では対象から外した（カタログを増やす話は別途）。

## スコープの簡略化（指示書の「作り込みすぎない」方針に沿って）

- 首脳会談は、プレイヤーが提案してから準備が整うまでの一本の流れに
  まとめた——他国側から突発的に招請が来る経路は今回作っていない
  （通知そのものは承諾／延期／辞退の3択で、双方向に拡張できる形）。
- 陣営は「立ち上げる」「関係値30以上の国を招く」だけの、ごく簡易な
  枠組み。脱退・陣営間の対立などは扱わない。
- 国際危機は2件のみ、短い応答選択肢だけを持つ——戦争・戦闘は扱わない。
- 貿易の充足率は関係値からの緩やかな連動で近似した簡略化で、実際の
  貿易統計・複雑な市場は再現していない。

## 開発

```
npm install
npm run dev      # http://localhost:5173/
npm test
npm run build
```

`main` への push で GitHub Actions がテスト・ビルドを実行し、GitHub Pages へ
公開する（`.github/workflows/deploy-pages.yml`）。本番ビルドのみ `base` に
`/simulator/` が付く。

## 次の段階で作るもの

指示書の方針どおり、戦争・戦闘・本格的な軍事シミュレーション・詳細な
諜報活動・詳細な貿易市場・本格的な国連システム・詳細な国際法・高度な
交渉AIは、このPhaseでは本格実装しない。Phase 5以降で、軍事→国会→
選挙→日本独自の政治システムを順番に追加していく計画。
