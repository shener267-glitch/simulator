# 総理大臣人生シミュレーター

総理大臣という職業に就いた一人の人間の人生をシミュレーションするゲーム。
政策だけでなく、家族・睡眠・疲労・食事・人間関係を含めて、その人生を体験する。

公開先: https://shener267-glitch.github.io/simulator/

## v0.1 の範囲

2026年6月6日（土）05:00〜08:00 の朝フェーズのみ。

前日6月5日に首班指名・親任式・内閣発足・記者会見・初閣議を終えた翌朝から始まる。

```
05:00  起床（固定）
       自由行動
06:10  官房長官から連絡（突発イベント）
       → 07:00のブリーフィングが06:30に繰り上がる
       自由行動
06:30  秘書官による朝のブリーフィング（固定・30分）
       自由行動
08:00  朝フェーズ終了 → 朝の記録
```

固定されているのは起床とブリーフィングの二点だけで、朝食・ニュース・SNS・
仮眠・妻との会話・資料・秘書官への相談はすべて時間を消費する「行動」として
プレイヤーが自由に選ぶ。

### 中核システム

行動は複数のセグメントに分かれていて、一区切りごとに「続ける／やめる」を選べる。
途中でやめれば、消化した分の時間だけを消費する。予定や突発イベントを跨ぐ
セグメントは中断され、実際に残っていた分だけが消費される。

体調（睡眠・疲労・空腹）は内部的に数値で持つが、画面には文章でしか出さない。

### 起床シーン

05:00の起床だけは、短いカットを一画面ずつ送る導入にしてある。文字送りの途中で
タップすると全文が出て、もう一度タップで次へ進む。この一文字ずつの表示は起床
シーンに限り、ニュース・会話・メニューでは使わない。時間は消費しない。

### 見た目

黒（#0B0D12）を地に、金（#C8A96B）を時刻・選択・見出しのアクセントとして使う。
赤（#C94B4B）は突発の連絡と中断だけに限る。書体は Noto Sans JP に統一し、階層は
太さと大きさで作る。時刻と英字ラベルにのみ Inter を使う。フォントの読み込みに
失敗しても端末標準の書体で成立するようにしてある。

### v0.1 で作っていないもの

外交・国会・選挙・内閣不信任・政策システム・派閥システム・午前以降のフェーズ、
突発イベントのランダム発生。いずれも今後のバージョンで設計する。

## 開発

```
npm install
npm run dev      # http://localhost:5173/
npm test
npm run build
```

`main` への push で GitHub Actions がテスト・ビルドを実行し、GitHub Pages へ
公開する（`.github/workflows/deploy-pages.yml`）。本番ビルドのみ `base` に
`/simulator/` が付く。
